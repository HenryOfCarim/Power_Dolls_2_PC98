# Advanced Power Dolls 2 (PC-98, Kogado 1996) — встановлення на жорсткий диск

Реалізація інструкції з [target-earth.net](https://www.target-earth.net/wiki/doku.php?id=blog:pc98_game_advancedpowerdolls2),
перевірена запуском у DOSBox-X. Усе нижче — виміряні факти, а не переказ вікі:
кожен абзац або підтверджений логом емулятора, або знімком екрана гостя.

---

## 1. Стан: що вже зроблено

| крок | стан |
|---|---|
| дев'ять дискет `.d88` → робочі образи 1.2 МБ | ✅ `_dbg\apd2_floppy\disk1..9.img` (перевірено власним FAT-читачем) |
| завантаження MS-DOS із дискети, запуск `INST.EXE` | ✅ |
| копіювання **всіх дев'яти** дискет | ✅ інсталятор пройшов 1→9, у лозі видно кожен обмін (`swaplist position N`) |
| том `KOGADO\PD2_3` на HDD | ✅ **30/30 файлів**, розміри збігаються зі списком у вікі, включно з `PD2DT.BND` = 7 228 225 Б |
| вільне місце на томі | ✅ 31 900 КБ (інсталятор вимагав 7680 КБ) |
| `GO.EXE` | ✅ запускається, малює власний екран |

FAT16, `AUTOEXEC.BAT` якого робить `CD \KOGADO\PD2_3` + `GO`).

## 2. Точний рецепт

### 2.1 Підготовка (один раз)

```powershell
# оригінальні .d88 узяти з архіву (у робочій папці disk1 був зіпсований)
python _dec\apd2_restore_d88.py --extract
# 1.2 МБ образи дискет + самоперевірка FAT/каталогу
python _dec\apd2_mkfloppies.py --out _dbg\apd2_floppy --check
# завантажувальна дискета, AUTOEXEC.BAT якої одразу робить B: + INST
python _dec\mkbootfloppy.py _dbg\drive\apd2_auto.img --script _dbg\_apd2_auto.bat
# цільовий жорсткий диск: MS-DOS 6.20, FAT16, 41 508 КБ вільно
python _dec\build_dos_hdd.py --out _dbg\hdd\apd2_install.hdi
# дискета 起動ディスク з вільним місцем (див. §4.2)
python _dec\apd2_mkbootdisk.py _dbg\apd2_floppy\bootdisk.img
```

Розкладка образів для запуску:

| пристрій | образ |
|---|---|
| `A:` | `_dbg\drive\apd2_auto.img` — MS-DOS 5.00A-H, з нього завантаження; `AUTOEXEC.BAT`: `B:` + `INST` |
| `B:` | список з **десяти** образів: `disk1.img` … `disk9.img`, `bootdisk.img` |
| `C:` | `_dbg\hdd\apd2_install.hdi` — цільовий диск |

Керується це конфигом `_dbg\apd2_install.conf` (або драйвером `_dec\apd2_drive.py`,
який додатково вміє екран, клавіші, обмін дискет і перевірку обміну по логу).

### 2.2 Що робить гість (і що робити вам)

Інсталятор малює власне вікно; у ньому є **два різні способи вводу**, і це
головна пастка:

* екран вибору пристрою приймає **Enter**;
* кнопки в діалогах 「了解」/「中止」 та варіанти на кшталт 「組み込む」/「組み込まない」
  приймають **тільки клік мишею** — інжектовані Enter/Space ігноруються (перевірено);
* зміна дискети відбувається **не кнопкою**, а реальною зміною носія: `F11+O`
  (host+O = «Swap floppy drive») або меню **Drive → Swap disk**. `Ctrl+F4` у цій
  збірці DOSBox-X не прив'язаний ні до чого.

Послідовність екранів:

| # | екран (як на ньому написано) | переклад | дія |
|---|---|---|---|
| 1 | `Advancedパワードール２インストールプログラム` | програма встановлення | чекати |
| 2 | `C: ハードディスク（IDE/SASI） 空き容量 32665600` / `D: ハードディスク（ＳＣＳＩ） …` | вибір пристрою | **Enter** (перший рядок) |
| 3 | `インストールディスクのコピーを始めます` + `インストールディスク2をドライブB:に入れてください。` | вставте дискету 2 у `B:` | `F11+O`, потім **клік 「了解」** |
| 4 | те саме з номерами 3…9 | дискети 3…9 | `F11+O` + клік |
| 5 | `起動ディスクをドライブA:に入れてください` | вставте завантажувальну дискету в `A:` | там уже DOS-дискета → **клік 「了解」** |
| 6 | `起動ディスクをドライブB:に入れてください` | те саме в `B:` | перемкнути `B:` на `bootdisk.img` (позиція 10) → клік |
| 7 | `ＸＭＳドライバを組み込みますか？` | встановити XMS-драйвер? | 「組み込む」(так) — тоді інсталятор сам пропише `CONFIG.SYS`; або 「組み込まない» |
| 8 | подяка + пропозиція перезавантажитись | — | клік, далі reboot |

Після цього інсталятор сам пише `CONFIG.SYS`/`AUTOEXEC.BAT` (шаблон із
`HD_INST.SCR`: `CD %D:\KOGADO\PD2_3` + `GO`) і кладе на дискету `BOOTDISK.ID`.

## 3. Робочий запуск гри

```
D:\KOGADO\PD2_3\GO        (у гостя, що завантажився з диска, це A:\KOGADO\PD2_3\GO)
```

`GO.EXE` показує мінімальний конфіг (FM або MIDI), як і описано у вікі.

## 4. Перевірені підводні камені

### 4.1 Емуляція

* **`IMGMOUNT … -fs none` не монтує взагалі.** У лозі немає жодного рядка
  `IMGMOUNT`, гість не бачить диска, а інсталятор каже
  「インストール可能なデバイスがありません» (немає придатного пристрою).
  Симптом попередніх спроб.
* **Гість бачить гвинт як `D:`**, коли завантажується з дискети, і як **`A:`**,
  коли завантажується з самого гвинта. Тому `CONFIG.SYS` із `DEVICE=C:\DOS\HIMEM.SYS`
  у другому випадку не спрацьовує — XMS треба ставити через сам інсталятор (§2.2, крок 7).
* **Обмін дискет треба перевіряти по логу DOSBox-X**: кожен обмін пише
  `Loaded drive 1 disk 0 from swaplist position N - "…\diskK.img"`. Це єдиний
  надійний спосіб знати, яка дискета насправді в дисководі.
* Під час копіювання тому емулятор зайнятий: повідомлення вікна обробляються із
  запізненням, тому обмін треба **повторювати** (у `_dec\apd2_drive.py` це вже так).

### 4.2 Дискета для `起動ディスク`

`power dolls 1\MS-DOS.FDI` — справжня NEC MS-DOS 5.00A-H, але її FAT вважає диск
**заповненим: вільно 6 КБ**. Тому фінальний крок падає з
「起動ディスクにファイルがかけません» (не вдається записати файли на
завантажувальну дискету), а на дискеті без системних файлів — з
「起動ディスクではありません» (це не завантажувальна дискета).

Лікування: `_dec\apd2_mkbootdisk.py` перезбирає дискету з її ж завантажувального
сектора і системних файлів (`IO.SYS` першим і суміжним, як вимагає MS-DOS) —
виходить 5 файлів і **1068 КБ вільно**.

### 4.3 Інструменти спостереження

* **Знімки VRAM через налагоджувач відстають від екрана.** Одного разу дамп
  показував `…ドライブA:…`, а вікно — `…ドライブB:…`. Правду дає
  `_dec\apd2_grab.py` — `PrintWindow` читає власні пікселі вікна (працює, навіть
  коли вікно перекрите іншими; звичайний знімок екрана в такому разі ловить чуже вікно).
* **Клавіші інжектуються в буфер клавіатури PC-98** (`0000:0502`, 16 слів).
  Якщо гість зайнятий (наприклад, стоїть у «Data error … Abort/Retry/Fail»),
  довгі рядки губляться: у буфері залишаються тільки останні символи.
* **Захоплена миша робить рухи відносними** — курсор гостя «пливе», і клік
  потрапляє не туди. Звільняти середньою кнопкою (або `Ctrl+F10`), тоді
  позиціювання абсолютне й клік лягає точно.

### 4.4 Інше

* Інсталятор **не докачує** часткове встановлення: кожен запуск `INST` починає
  копіювання з дискети 1.
* Якщо вікно DOSBox-X закрити посеред прогону, сесія гине (у лозі драйвера
  `windows of pid …: []`) — образ лишається в напівстані.
* `PD2DT.BND` **не є простим склеюванням** шести томів `PD2DT.000…005`: збігається
  перший том (1 250 253 Б після 51-байтового заголовка), далі розбіжність. Це
  узгоджується з нотатками про контейнер `BIGFILE` в `ADVANCED_PD2.uk.md`.

## 5. Перевірка результату з хоста

```powershell
python _dec\apd2_verify_hdd.py _dbg\hdd\apd2_install.hdi --compare --bnd _dbg\apd2_floppy
```

Дає список файлів тому, порівняння з таблицею з вікі й перевірку `PD2DT.BND`
проти дискет-томів. Очікуваний результат — `VERDICT: INSTALL LOOKS COMPLETE`
(30/30 файлів, розбіжностей у розмірах немає).

## 6. Що лишилося (відкрите)

1. **Завершити останню фазу інсталятора.** Без неї `GO.EXE` каже
   「ＰＯＷＥＲ ＤｏＬＬＳが正常にインストールされていません» (Power Dolls
   встановлено некоректно) — бракує маркерів, які пише саме ця фаза
   (`BOOTDISK.ID` у корені, `USERDISK.ID` у каталозі гри). Якщо додати їх вручну
   (`_dec\apd2_addfile.py`), `GO.EXE` **стартує** й малює свій екран, але просить
   CD: 「パワードールのＣＤがセットされていません» — тобто гра вважає, що це
   CD-режим установки. Правильне лікування — дати інсталятору `bootdisk.img`
   (він є) і дати йому завершити фазу 6–8 з §2.2.
2. **Асемблювання контейнера `PD2DT.BND`** (`.org`/`.chg`/`.idx` з `PD2DT.IDX`) —
   та сама відкрита тема, що й у `ADVANCED_PD2.uk.md`.
3. Пункт §6.1 зручно довести до кінця автоматично: `_dec\apd2_drive.py` уміє
   `disk N` (абсолютна дискета), `debug <команда>`, `swap`/`swapback` (з
   перевіркою по логу), а `_dec\apd2_click.py` — точний клік по кнопці діалогу.
